Ren'Py .rpy Translator

Локальный браузерный инструмент для перевода файлов локализации Ren'Py. Переводит только строки new "..." и незакомментированные строки диалогов.

Файл не отправляется целиком.
В API уходят только отдельные найденные строки.

Перетащите .rpy файл сюда

или нажмите, чтобы выбрать файл вручную

Можно указать свой LibreTranslate endpoint, например: http://localhost:5000/translate
